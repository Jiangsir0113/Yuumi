# Yuumi 1.3 Implementation Plan

> Execution: implement sequentially in the dedicated upgrade-v1.3 worktree. User has approved implementation and publication; no further design handoff is required.

**Goal:** Improve animation and input consistency, create spatially coherent toys and feeding, add a garlic rope scratcher with an interactive circular ball track, and publish a new release while preserving all older versions.

**Architecture:** Keep the deterministic behavior model and native transparent Qt window. Add a scene controller with independent world objects and contact-driven activity stages. Animation uses an interruptible posture graph, asynchronous decoding and flow, a common clock, and action execution time distinct from entry time.

**Tech Stack:** Python, PySide6, NumPy/OpenCV, generated PNG poses, 64 FPS WebP, PyInstaller, GitHub API/CLI.

## Task 1 — Input and companionship model

Files: cat_model.py, tests/test_model.py.
Add diagnostics for event-rate-independent touch, static contact, action entry timing and preference persistence. Replace per-event minimum time with elapsed contact integration. Add recent-action avoidance, preferred touch regions, curiosity/energy-sensitive choices and quiet-mode policy. Preserve old save migration and offline non-punishment.

## Task 2 — Animation pipeline

Files: animation_engine.py, assets, tools, tests/test_animation.py.
Add standing turn artwork and graph edge, ensure cyclic graph reversal uses shortest paths. Move all dynamic optical flow and fallback preparation off the UI thread with bounded latest-target work. Use lightweight fallback while work is pending. Keep target action phase paused during structural entry. Test direct turns, retarget continuity, worker thread execution and large-delta consistency.

## Task 3 — Scene objects and activities

Files: scene_model.py, scene_view.py, main.py, tests/test_scene.py.
Implement fixed world-coordinate bowls, moving balls with friction/collisions, cursor-based wand pursuit, and a persistent movable garlic scratcher. Separate rope scratching from circular-track batting. Gate care and play rewards on real contact/execution, make repeated commands idempotent, cancel stale targets immediately. Test cancellation, arrival/contact and orbital ball impulse.

## Task 4 — Native interaction and settings

Files: main.py, tests/test_gui.py.
Add scratcher controls, visible stop/put-away controls, pose-relative touch hotspots, double-click recognition, quiet mode and click-through control. Throttle hidden rendering while preserving lightweight model time. Update panel status/preferences/water display and truthfully describe actions.

## Task 5 — Assets and visual validation

Files: art-source, assets/props, tools/prepare_v13_assets.py, tools/make_v13_preview.py.
Use the supplied product reference for a rope-wrapped white garlic with green leaves on a wooden circular ball track. Generate matching cat scratch/standing-turn poses, register endpoints, encode new actions at 64 FPS. Inspect rendered contact, silhouette, track depth and action interruption.

## Task 6 — Verify and package

Files: tests, benchmarks.py, build.py, tools/verify_package.py, docs/VERIFICATION.md.
Run the complete unit/native interaction suite; cold/warm rapid-switch diagnostics; hidden rendering checks; visual scene preview; standalone exe checks from an unrelated empty directory with a clean PATH. Record measured frame gaps, response, memory limits and remaining limitations without universal FPS claims.

## Task 7 — Version and publish

Files: README.md, CHANGELOG.md, docs/DEVELOPMENT.md, docs/COMPATIBILITY.md.
Bump to v1.3.0, add a v1.2/v1.3 comparison and release notes. Upload reviewed tracked changes as a new commit without force updates. Create a new v1.3.0 tag/release and ASCII-named exe/preview/checksum assets. Verify remote file hashes and release digests. Assert v1.2.0 release ID/assets are unchanged; never delete or overwrite historical release files.
