# 悠米 v1.4.1 实施计划

- 场景以新请求接管成功为准提交吃喝动作。靠近目标期间保持走路，抓板两侧都根据真实接触点和可行站位判断。复现相邻切换、长距离、两侧及桌面边缘情况。
- 道具窗口缓存静态画面状态，位置、尺寸、余量、旋转或波纹变化时按需刷新。用 Qt 绘制事件统计验证静止道具不持续重绘，互动和进度仍可见。
- 后台解码完成时让正式帧逐渐接入当前相位，继续支持打断，不堵塞界面线程。完整动作保持 64 FPS 素材，区分实际选帧与窗口重绘，测试输入响应及设备场景。
- 更新 README 和变更日志。打包并测试最终 Windows x64 exe，确认至少 60 FPS 的本机动作采样目标，通过后用新标签发布。对比全部历史标签和附件哈希。自主玩法留给 v1.5。
