# v1.4.0 验证记录

2026-11-13 在本机 Windows x64 环境测试。以下是本机观察，不是跨设备帧率保证。本次没有调整 CPU 指令集兼容目标。

## 正确性

- 62 项测试通过。包含输入频率一致性、静态接触、过渡阶段计时、偏好存档、直接转向、后台光流线程、部位命中、双击、真实道具点击与拖动、取消旧任务、实际到达后吃喝、球体摩擦/碰撞和圆槽约束。
- 最终独立 exe 在删除 Python/Qt 环境变量、PATH 仅含 System32、无关空工作目录中启动成功，28 种行为均渲染通过。
- 独立 exe 检查还覆盖猫抓板 PNG、SOLO 与 SOLO SE、弗列加特猫粮袋和猫条、两个反向素材、设备等比显示、切换抓绳/拨槽球、槽球运动、停止保留道具和收起。
- 64 FPS 预览来自真实窗口/场景渲染器的受控时间线，包含 3712 帧；记录到 3 次抓绳接触和 1 次猫咪拨槽球接触。预览不是实时吞吐率测试。

## 独立 exe 实时性能

实际执行最终 exe，全新独立存档、100% 大小、鼠标穿透以隔离桌面输入、干净 Python/Qt 环境、空工作目录。每个动作预热两秒，再测量两秒；诊断会循环短的一次性动作，正常玩法不循环它们。

| 指标 | 28 种行为的本机结果 |
| --- | ---: |
| 素材采样率 | 64 FPS |
| 最低窗口渲染率 | 115.76 FPS |
| 最低动作采样事件率 | 63.49 次/秒 |
| 最大稳定播放帧间隔 | 16.00 ms |
| 各动作 P99 帧间隔中的最大值 | 13.59 ms |
| 最大冷切换帧间隔 | 17.04 ms |

另以相同源代码的原生窗口运行抓绳、拨槽球、追小球、喂食、饮水及猫条六个场景，每项预热五秒再测量三秒，同时记录独立道具窗口；最低猫咪渲染率为 117.53 FPS。喂食器、饮水机、猫条、小球、猫抓板与猫咪共同在场的检查也已包含。

v1.2 的记录出现过 48.1 ms 冷切换间隔。v1.3 将预热与稳定播放分开记录，序列和缓存状态并非完全相同，因此这些数字不应解释为严格控制条件下的倍数提升。

## 限制

本项目仍是二维图片驱动动画。跨大姿势的过渡可能有轻微轮廓混合；部位区域是随轮廓/姿势变换的近似热点，不是三维解剖绑定。复杂桌面布局、多显示器、不同缩放和更多 Windows 设备仍需继续验证。

历史版本按 [发布规则](RELEASING.md) 保留，v1.2 的[原验证记录](VERIFICATION.md)未替换。
