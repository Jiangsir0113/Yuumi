# 后续改进建议

基于 v1.3.0 实测截图和当前实现，v1.3.1 已先修复抓板拉伸、过大、低位接触及原地重玩流程。以下为下一轮建议，尚未作为新功能加入本次修复。

| 优先级 | 建议 | 原因与方向 |
| --- | --- | --- |
| 高 | 互动栏悬停显示、闲置收起 | 当前有道具时控制条持续显示，容易影响桌面观感。可默认折叠，只在悬停或互动时展开，保留右键和托盘停止入口。 |
| 中 | 道具大小独立调节 | 当前跟随桌宠大小统一缩放。增加小/中/大或单独滑块，方便不同屏幕密度和个人偏好；小球视觉尺寸缩小时仍保持可点击热区。 |
| 高 | 先看球、再判断时机出爪 | 当前只在距离满足时给球施力，但动作仍会循环，因此会出现挥空。可以先观察球的位置和速度，预计进入爪子范围时再出手，扑空后自然停顿。 |
| 高、长期 | 统一现有姿势的脸型、体型和落脚点 | 独立生成整张姿势会带来细微身份和比例差异。先加强素材配准和关键点检查，再逐步采用稳定身体与局部肢体的分层动画。 |
| 中 | 自选活动区域和更稳定的道具摆放 | 允许圈定桌面一角，减少遮挡工作区；摆放新道具时同时考虑现有道具与猫咪站位。 |

建议下一轮先做互动栏自动收起和独立道具大小，再改善拨球时机；统一角色动画体系应作为单独版本规划。
