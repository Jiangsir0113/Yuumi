# v1.2 验证记录

以下为开发机器在 2026-11-12 的本机观察，不代表所有硬件或系统配置均已兼容。

## 自动化测试

27 项测试通过，涵盖：

- 全部姿势节点之间的可达性、过渡中途反向。
- 新动作接管时首帧的像素连续性，以及已有混合过程中的再次打断。
- 走路切换小跑时保留相位、局部动作选择最近姿势。
- 翻肚皮、摸肚皮和侧躺从行为与运行清单中移除。
- 抚摸部位、鼠标拖动、屏幕边界、陪伴小屋设置和玩具取消。
- 连续抚摸、温柔拒绝与恢复、打断吃喝后的部分营养记录。
- 本地存档、损坏存档恢复及旧名字迁移。

## 独立 exe

单文件 Windows exe 在清除 Python／Qt 环境变量、将 PATH 限于 System32、切换到无关空目录后启动成功，26 种保留行为全部渲染成功。

| 指标 | 本机结果 |
| --- | ---: |
| 动作素材采样率 | 64 FPS |
| 最低动作更新率（26 项逐项测试） | 63.57 次／秒 |
| 最低窗口渲染率 | 121.99 FPS |
| 最大观察到的冷切换帧间隔 | 48.1 ms |

每项动作测试两秒。吞吐诊断会循环一次性短动作；正常玩法保持一次性动作语义。渲染率、动作更新率与显示器实际显示频率不同；一次冷切换停顿与平均帧率也不等价，不能据此承诺任意机器每帧的实时性。

## 切换预览

[H.264 动作预览](media/transitions-64fps.mp4) 使用真实渲染器输出，640×400，64 FPS，共 832 帧。脚本包含 15 次目标切换，各次接管首帧与前一已显示姿势的最大像素误差为零。

首帧连续不等于后续姿势具有严格的三维物理一致性；本项目仍是生成图片与像素运动过渡组成的动画。

## 已知验证缺口

后续在另一运行环境出现了 NumPy `X86_V2` baseline 不支持错误。当前版本需要相应 CPU 指令集；低指令集兼容版尚未验证，见[兼容性说明](COMPATIBILITY.md)。实际多显示器配置、Windows ARM 模拟层及更多 Windows 设备也需要进一步测试。
